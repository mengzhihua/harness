# Harness

自研 **Coding Agent 运行时**：让大模型在真实仓库里动手改代码、跑检查、被插件扩展、被轨迹回放。

同一套运行时驱动 TUI、`exec`、SDK，以及未来的 IDE / Cloud。模型可换。

> 当前只有技术方案，**还没有可启动的进程**。有运行时的标志见下文。

## 术语（先看这个）

```text
模型            脑子。DeepSeek / GPT / Claude / 自建，可换。
Harness         本仓库要做的产品 = Agent 运行时。
Agent 运行时    常驻进程：组 prompt、调模型、执行工具、审批、加载插件、写轨迹。
执行运行时      工具实际跑在哪：本机、Docker、云 VM。可替换的后端。
插件            往运行时上挂的扩展（工具 / skill / hook / MCP / 命令 / 模型适配）。
轨迹            一次任务的黑匣子。模型看见的、手做的，全部可回放。
```

**还没有运行时。** P0 把契约测通之后，P1 交出第一个可启动的 Agent 运行时。
